# Voto-EML

Página de votação dos bichinhos de pelúcia da Ecoescola Monteiro Lobato.

Abra `index.html` no navegador para usar. Não é necessário instalar dependências.

Os votos são salvos no navegador do aparelho utilizado e não são sincronizados entre dispositivos.

Consulte [LEIA-ME.md](LEIA-ME.md) para instruções e [os créditos das imagens](imagens/creditos.md).
